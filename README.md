# S&P 500 Risk and Regime Analysis

This project analyzes S&P 500 market regimes and evaluates risk-off forecasts using several machine-learning and statistical models.

The notebook compares:

- Hidden Markov Models
- Logistic regression
- Gradient boosting
- A 200-day moving-average benchmark
- Walk-forward evaluation
- Drawdown forecasting
- Risk-managed investment strategies
- Bootstrap uncertainty and placebo tests

## Important limitation

This is a retrospective analysis. The sample and test periods were inspected during development, so the results should not be treated as an untouched confirmatory test.

The notebook downloads live data from Yahoo Finance and FRED. Results may change slightly when the notebook is run later.

This project is for research and educational purposes only. It is not investment advice.
